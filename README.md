- 물리학·화학·생명과학·지구과학 분야 화면

- 「모더나의 맞춤형 암백신은 어떻게 작동할까?」 영상·전체 기작·연구 단계·공식 출처 페이지
- 「하늘에서 떨어지는 빗방울은 어떤 모양일까?」 형상 해설 페이지 연결
- 일상 속 과학과 시뮬레이션 탐색 화면
- 모바일·데스크톱 반응형 레이아웃
- 「떨어지는 표적과 발사체」 학습 페이지

## 로컬 확인

사이트 루트에서 정적 HTTP 서버를 실행한 뒤 브라우저로 접속합니다.

```bash
python3 -m http.server 8000
```

검산 테스트:

```bash
node --test tests/*.test.cjs
```

GitHub Pages 프로젝트 경로에서도 작동하도록 내부 자원과 링크는 상대경로를 사용합니다.
