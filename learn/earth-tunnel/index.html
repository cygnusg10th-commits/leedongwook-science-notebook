지구를 관통하는 터널에 떨어지면?

지구가 균일한 밀도의 구이고 터널이 완전한 진공이라면, 낙하체는 중심에서 멈추지 않습니다. 중심을 가장 빠르게 통과한 뒤 약 42분 12초 만에 반대편 입구에 도착합니다.

핵심 정리

중력 0과 속도 0은 같은 말이 아닙니다

구각 정리로 중력의 크기를 먼저 구한 뒤, 운동 방정식으로 중심 통과와 반대편 도착을 설명할 수 있습니다.

1
안쪽 질량만 끌어당긴다

현재 위치보다 바깥쪽 구각의 중력은 서로 상쇄됩니다.

2
중심에서 중력은 0, 속도는 최대

힘이 사라지는 순간에도 이미 얻은 속도 때문에 그대로 중심을 통과합니다.

3
반대편에서 속도는 다시 0

마찰이 없으면 밖으로 날아가지 않고 다시 중심을 향해 떨어집니다.

먼저 가정을 고정합니다

이 네 조건이 바뀌면 계산의 결론도 달라집니다.

조건 01균일한 밀도

지구 전체가 같은 밀도인 완전한 구라고 가정합니다.

조건 02완전한 진공

공기 저항과 마찰이 없어 운동에너지가 줄지 않습니다.

조건 03자전 없음

동쪽으로 휘게 만드는 회전 효과를 제외합니다.

조건 04중심을 지나는 직선

터널은 지구의 지름을 따라 정확히 반대편까지 이어집니다.

구각 정리 계산

구각 안쪽의 중력이 왜 0인지 직접 적분합니다

반지름 a, 표면질량밀도 σ인 얇은 구각을 생각합니다. 관찰점 P는 중심에서 r만큼 떨어져 있고, 먼저 r < a인 내부를 계산합니다.

1단계

같은 위도의 고리를 잡습니다

중심축과 각 θ를 이루는 작은 고리의 면적과 질량, 고리에서 P까지의 거리는 다음과 같습니다.

dm = σ · 2πa² sinθ dθ
s² = a² + r² − 2ar cosθ
2단계

중력 퍼텐셜을 적분합니다

고리 전체는 P에서 같은 거리 s에 있으므로 퍼텐셜을 먼저 더하면 벡터 성분을 따로 나눌 필요가 없습니다.

Φ(r) = −2πGσa² ∫₀π sinθ dθ / s
sinθ dθ / s = ds / ar
3단계

적분 구간을 거리로 바꿉니다

θ가 0에서 π로 갈 때 내부점에서 구각까지의 거리는 a−r에서 a+r로 변합니다.

Φ(r) = −2πGσa/r [s]₍a−r₎a+r
Φ(r) = −4πGσa = −GMshell/a

결론: 내부 퍼텐셜은 위치 r과 무관합니다

Mshell = 4πa²σ이므로 구각 내부의 퍼텐셜은 어디서나 같은 상수입니다. 따라서 g(r) = −dΦ/dr = 0입니다. 반대로 r > a에서는 적분 구간이 r−a부터 r+a가 되어 Φ(r) = −GMshell/r가 됩니다. 즉 구각 바깥에서는 모든 질량이 중심에 모인 것처럼 작용합니다.

원리

구각 정리에서 복원력까지

현재 위치보다 바깥쪽 구각은 모두 0을 기여합니다. 균일 밀도 ρ에서 반지름 r 안쪽의 질량만 합치면 다음과 같습니다.

M(r) = (4/3)πρr³ = M(r/R)3
a(r) = −GM(r)/r² = −(GM/R³)r
g0 = GM/R² ⇒ a(r) = −(g0/R)r

가속도가 중심에서의 거리에 비례하고 방향은 항상 중심 쪽이므로 단순 조화 운동입니다.

d²r/dt² + (g0/R)r = 0
r(t) = R cos(ωt), ω = √(g0/R)

R = 6,371 km, g0 = 9.80665 m/s²를 쓰면 ω = 0.00124067 s⁻¹입니다. 중심에서는 위 식의 극한으로 가속도가 0이 됩니다.

계산에서 나오는 네 숫자

위치·속도·가속도는 하나의 같은 운동식에서 계산됩니다.

지표면 → 중심21분 6초

가속하면서 중심에 도착합니다.

중심 최대 속도7.90 km/s

중력은 0이지만 속도는 가장 큽니다.

지표면 → 반대편42분 12초

반대편 입구에서 속도가 0이 됩니다.

한 번의 완전한 왕복84분 24초

마찰이 없다면 같은 운동을 반복합니다.

공기와 자전을 넣으면?

이상적 계산에서 제외한 두 효과를 따로 살펴봅니다.

이 계산의 이상적 조건

자전이 없으므로 궤적은 중심선을 따라 곧고, 진공이므로 에너지가 줄지 않아 양쪽 입구 사이를 계속 왕복합니다.

공기 + 자전 조건

자전은 궤적을 동쪽으로 휘게 하고, 공기 저항은 운동에너지를 줄입니다. 좁은 터널에서는 조건에 따라 벽에 닿을 수 있고, 충분히 넓어도 진폭은 줄어 중심 부근으로 수렴합니다.

주의: 실제 지구에서는 고온·고압, 밀도 층상 구조, 터널의 붕괴와 생존 문제까지 고려해야 하므로 이 계산처럼 통과할 수 없습니다. 이 페이지는 조건을 고정한 사고실험입니다.
